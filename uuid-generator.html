What is a UUID?

A UUID (Universally Unique Identifier) is a 128-bit value used to uniquely identify information in software. UUID v4 is randomly generated, making collisions practically impossible.

When should I use UUIDs?

Use UUIDs as primary keys in databases, session tokens, file names, or any scenario where you need a unique identifier that doesn't require a central authority to generate.
