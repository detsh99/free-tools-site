📄 Her Tool Sayfasında Olması Gerekenler (Şablon)

Yeni bir tool sayfası yaparken bu şablonu kopyala ve doldur:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  
  <!-- SEO: Her sayfada değiştir -->
  <title>[TOOL ADI] — DetshTool</title>
  <meta name="description" content="[150-160 karakter açıklama. İngilizce. Anahtar kelime içer.]" />
  <meta name="robots" content="index, follow" />
  <link rel="canonical" href="https://detsh-tool.vercel.app/[dosya-adi].html" />
  
  <!-- Schema.org -->
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "WebApplication",
    "name": "[Tool Adı]",
    "description": "[Kısa açıklama]",
    "url": "https://detsh-tool.vercel.app/[dosya-adi].html",
    "applicationCategory": "UtilityApplication",
    "offers": { "@type": "Offer", "price": "0" }
  }
  </script>
</head>
<body>
  <!-- NAV (aynı kalır, sadece son breadcrumb değişir) -->
  <nav>...</nav>
  
  <main>
    <h1>Free [TOOL ADI]</h1>    <!-- H1 mutlaka olmalı -->
    <p>Kısa açıklama...</p>
    
    <!-- TOOL İÇERİĞİ -->
    
    <!-- SEO İÇERİK BLOĞU (önemli!) -->
    <section>
      <h2>What is a [Tool Adı]?</h2>
      <p>Açıklama...</p>
      <h2>How to use...</h2>
      <p>...</p>
    </section>
  </main>
  
  <footer>...</footer>
</body>
</html>

🔗 Ana Sayfada Tool Linkleri

Ana sayfandaki her tool kartına şu şekilde link ekle:

<!-- index.html'de her tool kartına -->
<a href="/password-generator.html">
  <div class="tool-card">
    🔐 Password Generator
  </div>
</a>
💡 İpucu: Her tool sayfası ekleyince sitemap.xml'i de güncelle ve Search Console'dan "URL İndeksleme İste" diyerek o URL'yi gönder.
